CLIs

Two families: forge (the platform: capabilities + infra) and orch (the agent harness that builds Dorinda itself).

forge infra — the stack (local execution, repo = selector)

forge infra bootstrap --env prod-a   # ONCE per env: folder/project/billing/APIs/state/WIF (idempotent)
forge infra lint | plan | apply | status | outputs | verify | destroy | untaint
forge infra release-image --env prod-a --service dorinda-api --image REPO@sha256:…  # code plane
GuardEnforced how
apply is CI-onlylocal demands --local --allow-local-apply; both bootstrap uses are SPENT
a zero exit code is not evidenceapply re-plans until empty; release-image waits for revision Ready
contract mismatch fails fastconsumers refuse to plan before the published contract satisfies their major
prod destroy--i-know-this-is-prod, never in CI

orch — the harness

orch plan goals/<slug>.md    # Planner → RunSpec DAG
orch run <id> [--dry-run]    # jailed workers, gates, approvals
orch ledger list · orch relay # the capability wind-tunnel
