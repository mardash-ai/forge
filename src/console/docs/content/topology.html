🌑 The box is dark (2026-07-31). All 11 Dorinda containers — app, data-plane, its Postgres, web, site, and the old Grafana/Loki/Prometheus stack — are stopped, and every host was re-verified green afterwards. It still runs four unrelated projects of Mark's behind the shared proxygen Traefik, which is why "stop everything on the box" was the wrong instruction. All 15 containers are also set restart=no, so a reboot brings none of them back — including a second forge-os data-plane that had exited on its own and would have resurrected under unless-stopped. DNS is fully clear: *.dorinda.ai was repointed on 2026-07-31, so no record anywhere resolves to the box. Nothing was deleted; the old Postgres volume is intact but the data is disposable.

What is still on the Mac

The box is the rollback (one GoDaddy API call per host puts traffic back) and still hosts Grafana/monitoring via the DNS wildcard. It is otherwise off-path. Decommission after Phase 2b + a quiet week.

Availability posture (deliberate)

Cloud SQL is zonal with backups + PITR — the §9.9 decision: availability upgrades (regional HA, cross-region replica) are runtime settings purchasable later, not architecture. Cloud Run is multi-zone automatically.
