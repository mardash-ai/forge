Connectors & SDKs

Dorinda's "SDK" today is its MCP surface — the connector contract AI hosts consume — plus the service-token pattern for first-party clients.

The user contract (the only assumptions allowed)

Install the connector → open a NEW chat → type “Use Dorinda.” Everything else must Just Work — a fix that lives in user behavior is not a fix.
