### Changed

- `docs/architecture/PLATFORM_MODEL.md` is now generated by `npm run generate:platform-model` from
  `platform-model.json` and committed; the CI drift guard covers both files so a stale rendering
  fails the build.
- The hand-written July topology page (`02-runtime-topology.md`) and call-paths page
  (`03-call-paths.md`) are retired; each location now carries a one-paragraph pointer to
  `PLATFORM_MODEL.md` with a note directing readers to surviving design-rationale docs
  (`01-container-strategy.md`, `05-adoption-model.md`).
- The hand-written capability catalog (`04-capability-catalog.md`) is retired; each capability,
  plane, endpoint, resource type, and event is now rendered in the generated `PLATFORM_MODEL.md`.
- `README.md`: removed the hand-maintained capabilities table and HTTP route code block; replaced
  with pointers to `docs/architecture/PLATFORM_MODEL.md`.
- `docs/architecture/README.md`: updated reading-order table to reference the generated
  `PLATFORM_MODEL.md` instead of the retired pages; preserved the two-planes design-rationale prose.

### Fixed

- `tests/version-script.test.ts`: the end-to-end version-bump test now restores
  `docs/architecture/PLATFORM_MODEL.md` in `afterAll`, so the working tree is clean after every
  `npm test` run (previously the test left `PLATFORM_MODEL.md` stamped with
  `v99.0.0-version-script-test`, which failed the CI drift guard on the next push).
